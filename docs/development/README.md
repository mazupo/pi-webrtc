# Development

Build pi-webrtc from source, and learn how the code is organized. You only need this to change pi-webrtc itself. The [releases](https://github.com/mazupo/pi-webrtc/releases) are ready to use.

- [Build from source](build.md): build pi-webrtc on a Raspberry Pi or a Jetson.
- [Architecture](architecture.md): how frames move from the camera to WebRTC and to the recorder.
